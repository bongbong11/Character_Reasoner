# Character Reasoner

SillyTavern용 **시트 정규화 테스트 확장**입니다.

현재 단계에서는 캐릭터 / 페르소나 / NPC 시트와 선택한 연결 로어북 항목을 읽어, 이후 장면별 검색에 사용할 수 있는 짧은 구조화 레코드로 변환합니다. Jev 판정, 임베딩 검색, 실제 프롬프트 주입은 아직 하지 않습니다.

## 설치

SillyTavern의 **확장 → 확장 설치**에서 아래 주소를 사용합니다.

```text
https://github.com/bongbong11/Character_Reasoner.git
```

설치 후 새로고침하면 채팅 입력창 주변에 사람 아이콘이 생깁니다.

## 연결

별도 API 키를 저장하지 않습니다.

1. 기존 씬판독기에 저장된 `SillyTavern 연결 프로필`이 있으면 우선 사용합니다.
2. 없으면 Connection Manager에서 현재 선택된 프로필을 사용합니다.
3. 모델/키/주소는 기존 SillyTavern 연결 프로필 설정을 그대로 따릅니다.

요청 시 SillyTavern의 `json_schema` 구조화 출력을 사용합니다. 따라서 지원되는 Gemini / NanoGPT(OpenAI 호환) 연결에서는 스키마가 API 요청에 함께 전달됩니다.

## 사용

- **캐릭터**: 이름 + 원본 시트 입력. `연결 로어북 가져오기`로 현재 캐릭터의 기본/보조 로어북 항목을 불러와 복수 선택할 수 있습니다.
- **페르소나**: 이름 + 페르소나 시트 입력. 현재 페르소나에 연결된 로어북이 있으면 항목을 불러와 복수 선택할 수 있습니다.
- **NPC**: 이름 + NPC 시트만 입력합니다.
- `컴파일`을 누르면 JSON 결과가 표시됩니다.
- `결과 복사`로 그대로 복사해 검수에 사용할 수 있습니다.

## 현재 출력 종류

- `fact`
- `core`
- `value`
- `relationship`
- `knowledge`
- `reaction`
- `expression`
- `boundary`
- `capability`

각 레코드는 현재 장면 검색에 사용할 `when`, 실제 캐릭터 제약인 `rule`, 원문 강도를 보존하는 `modality`, 출처 추적용 `source_ids` 등을 가집니다.

## 범위

이 저장소는 먼저 **시트 분해 품질만 검증하기 위한 시험판**입니다. 결과 형식이 안정되면 본 씬판독기의 고급 인물 판정 쪽에 이식하는 것을 전제로 합니다.
